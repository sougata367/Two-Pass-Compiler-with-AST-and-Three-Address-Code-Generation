# Two Pass Compiler with AST and Three Address Code Generation

## Overview
This project implements a two-pass compiler system with Abstract Syntax Tree (AST) construction, symbol table management, scope handling, and three-address code generation.

## Features
- Abstract Syntax Tree (AST) generation
- Symbol table implementation
- Scope table management
- Intermediate code generation
- Three Address Code representation

## Technologies Used
- C++ Programming Language
- Compiler Design Concepts

## Project Structure

- `input.c` - Main input/test program
- `ast.h` - AST related implementation
- `symbol_table.h` - Symbol table implementation
- `scope_table.h` - Scope management
- `three_addr_code.h` - Three address code generation
- `script.sh` - Build/run script

## How to Run

Run the script:
bash script.sh
